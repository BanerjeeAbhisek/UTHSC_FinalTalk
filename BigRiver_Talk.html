Two packages, one statistical workflow

High-dimensional data

Many correlated variables, few samples, multiple assays, or a response to predict.

→

BigRiverEssence

Extract low-dimensional, sparse, supervised, or shared structure.

→

BigRiverPlots

Turn scores, loadings, variance, and predictions into interpretable graphics.


The interface between the packages is not a special object—it is the statistical output itself.

The obstacle is not just size

A familiar omics geometry

brRng = function(seed) {
  let s = seed >>> 0;
  return () => {
    s = (s + 0x6d2b79f5) >>> 0;
    let t = s;
    t = Math.imul(t ^ (t >>> 15), 1 | t);
    t ^= t + Math.imul(t ^ (t >>> 7), 61 | t);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

Compression is a controllable trade-off

Add components automatically or drag the slider. More structure is recovered, but the representation grows. 

compressionData = {
  const rng=brRng(41), n=22, p=46, R=7;
  const U=[],V=[],s=[8.5,6.0,4.2,3.0,2.0,1.3,.8];
  for(let r=0;r<R;r++){
    let u=d3.range(n).map(i=>Math.sin((r+1)*Math.PI*i/n+r*.7));
    let v=d3.range(p).map(j=>Math.cos((r+1)*Math.PI*j/(p/2)+r*.45));
    const nu=Math.hypot(...u),nv=Math.hypot(...v); U.push(u.map(x=>x/nu));V.push(v.map(x=>x/nv));
  }
  const M=d3.range(n).map(i=>d3.range(p).map(j=>d3.sum(d3.range(R),r=>s[r]*U[r][i]*V[r][j])+.025*(rng()-.5)));
  return {n,p,R,U,V,s,M,max:d3.max(M.flat(),x=>Math.abs(x))};
}

The PCA API keeps the workflow explicit

using BigRiverEssence

m = pca(X;
    k = 4,
    standardize = true
)

scores = pca_transform(m, X)
X̂ = pca_invtransform(m, scores)

m.loadings
m.propOFvar
Fit
Estimate ordered directions from the training matrix.
Transform
Represent observations in component space.
Invert
Map scores back to an approximation of the original variables.

The model stores what downstream graphics need: scores, loadings, and proportion of variance.

  • The point is the small, predictable API surface.
  • Mention that observations are rows and variables are columns for the single-matrix methods.
  • Timing: 1.5 minutes.
  • [Sources] https://senresearch.github.io/BigRiverEssence.jl/dev/pca_tutorial/

The design principle

  1. Fit with a method named for the statistical task.
  2. Read ordinary matrix outputs.
  3. Send those outputs to a plot named for the question.
  4. Customize through familiar Plots.jl attributes.
